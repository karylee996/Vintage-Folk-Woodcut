# Vintage-Folk-Woodcut

A reusable image skill for turning travel photography into 4:5 vertical posters: unchanged original on top, eight-color vintage folk woodcut below, generous margins and a location postmark.

Read [SKILL.md](SKILL.md) for exact proportions, colors and carved-mark rules.

## 调用语
请严格读取 SKILL.md，以我上传的照片作为唯一场景来源，生成竖版4:5上下各占50%高度的复古民间木刻旅行海报。上半原图完全保持不变；下半仅使用8种色彩（包含纸张及邮戳），场景须完整限定在78%画布宽的矩形中，采用粗而清晰的手工雕版刻线，矩形外保留宽幅留白，下方居中添加准确地点的单色邮戳。
